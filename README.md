# Vehicle Route Optimization

A Vehicle Routing Problem (VRP) solver built using Genetic Algorithms to find efficient routes while keeping the workload balanced across vehicles.

The project uses PMX crossover, mutation, and tournament selection to evolve better solutions. It also includes a Streamlit interface where users can generate or upload location data, configure GA parameters, visualize routes, and download the final solution as a CSV.

## Tech Stack
- Python
- Genetic Algorithms
- DEAP
- Streamlit
- NumPy / Pandas
